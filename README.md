# 🎵 LiveLog - ライブ参戦記録アプリケーション

自身の趣味である音楽ライブやフェスの参戦記録を、ブラウザ上で手軽に保存・管理できるアプリケーションです。
カジュアル面談にて、貴社のカルチャーや西日本支社のビジョンに深く共感し、「言葉だけでなく行動で熱意を示したい」という思いから作成しました。
ユーザーの視覚的な体験と利便性を意識し、フロントエンドのJavaScriptによる状態管理とLocalStorageを活用したデータ管理を中心に据えて開発しました。

## 🔨 主要機能
1. **CRUD機能（登録・一覧表示・削除）**
   - 日付、アーティスト/フェス名、会場名、メモをデータとして登録・保持・削除が可能です。
2. **データの永続化（LocalStorage）**
   - 今回はサーバーなしで動作させているため、ブラウザのLocalStorageを活用。
3. **入力バリデーション（JavaScript）**
   - 必須項目（日付、アーティスト、会場）の未入力を検知し、ユーザーにアラートで通知する制御を実装。
4. **UX配慮（削除前確認メッセージ）**
   - 誤操作によるデータ削除を防ぐため、削除ボタン押下時に「本当に削除しますか？」という確認ダイアログを挟む設計にしています。

---

## 🎨 UI/UXへのこだわり
- **ライブハウスの臨場感を意識したデザイン**
  ライブハウスの雰囲気を再現したいと思い黒を基調とした背景に、アクセントカラーとして鮮やかなピンクを採用しました。音楽ライブの熱量や臨場感を視覚的に表現できたと感じています。
- **直感的なカードレイアウト**
  登録された記録が1つのライブチケットのように見えるレイアウトを採用し、過去の参戦履歴を振り返りやすくしています。
